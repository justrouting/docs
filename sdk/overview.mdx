# SDKs

Use the official JustRouting SDKs to integrate routing capabilities into
your application without manually building HTTP requests.

JustRouting SDKs provide simple, typed interfaces for:

- Driving and motorcycle routes
- Distance matrices
- Map Matching
- Trip
- Nearest
- Geocoding
- Fleet optimization

All SDKs connect to the same JustRouting API and support Southeast
Asia-focused routing.

## Available SDKs

| Language | Package | Installation | Source |
| --- | --- | --- | --- |
| Python | `justrouting` | `pip install justrouting` | [py-client](https://github.com/justrouting/py-client) |
| Go | `github.com/justrouting/go-client` | `go get github.com/justrouting/go-client` | [go-client](https://github.com/justrouting/go-client) |
| JavaScript / TypeScript | `@justrouting/client`  | `npm install @justrouting/client` | [js-client](https://github.com/justrouting/js-client) |

## Quick Start

All SDKs follow the same workflow:

1.  Create a client with your API key
2.  Send a routing request
3.  Use the response in your application

## API Key

Create a free API key from the JustRouting dashboard.

Each SDK automatically authenticates requests using your API key.

Environment variable:

``` bash
export JUSTROUTING_API_KEY="your_api_key"
```

## Coordinates

JustRouting uses GeoJSON coordinate order:

``` text
[longitude, latitude]
```

Example:

``` text
Singapore CBD:
[103.8198, 1.3521]
```
